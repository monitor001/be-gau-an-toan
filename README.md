# Bé Gấu An Toàn

Game web giáo dục an toàn cho trẻ (prototype), chơi cùng người lớn.

**Thử ngay:** sau khi bật GitHub Pages, mở link dạng  
`https://<user>.github.io/be-gau-an-toan/`

## Cảnh báo quan trọng

- Đây là **prototype thử nghiệm**, **chưa** được chuyên gia / Bộ / giáo viên phê duyệt.
- **Không** thay giám sát người lớn hay hướng dẫn an toàn chính thức.
- **Không** thu thập tên, số điện thoại hay dữ liệu cá nhân của trẻ.
- Module **An toàn cơ thể** cần phụ huynh/GV đọc trước khi dùng với trẻ.

## Nội dung

| | |
|---|---|
| Module | 12 |
| Bài học | 100 |
| Tình huống | 500 |
| Lộ trình | Mầm non 3–6 · Tiểu học 1–5 · Tất cả |
| Âm thanh | Piper VI (MP3 sẵn) + Web Speech `vi-VN` dự phòng |
| Minh họa | Ảnh RESULT (X đỏ + người lớn xua tay) |

## Chạy local

```bash
python serve.py 127.0.0.1 5177
```

Mở http://127.0.0.1:5177/
